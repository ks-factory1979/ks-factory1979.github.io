# 10の塔

数字で10をつくり、れんがを集めて塔を育てるゲームです。GAS正式版v2.0.14「ペアおちリザルト統一版」を基にしたGitHub Pages移植版です。

**GitHub Pages一般公開版**。Checkpoint 1〜5、紹介文・カバー・最終公開はユーザー承認済みです。記録・対戦はそれぞれ正式版とは別のGASへ接続しました。承認されたGrid・Flexbox・clamp()の配置を維持し、幅850px以下の縦画面はスマホ・タブレット配置、高さ540px以下の横画面は盤面を左・プレビューと操作を右に並べる配置へ切り替えます。

## 配信と記録

HTML・CSS・ゲーム・画像60点・BGM9曲は静的ファイルとして配信します。画像は元の埋め込みデータをそのまま復元し、BGMはZIP内の正式MP3を使用しています。ゲームのルール、PC表示、音量・曲順・フェード・連鎖SEを引き継いでいます。

自己ベストと設定は端末・ブラウザに保存します。GAS版とGitHub版は配信元が違うため、自己ベスト・設定・対戦復帰情報は自動では引き継がれません。自動移行機能はありません。データ初期化は10の塔の保存キーだけを消し、同じサイトの他アプリの記録を保持します。

記録Bridgeは`submitFallingResult` / `submitPairFallingResult`の2種類だけを扱います。`config.js` の `recordGasWebAppUrl` が未設定の場合は接続せず、共有記録カードは読み込み失敗を表示します。元版のresultId・再送・画面世代の確認と、端末の自己ベスト保存を維持します。開発配置モードから記録APIへ送信しません。通常ページへ検査用の記録・成功応答を混ぜません。オンライン対戦は新規対戦GASへの部屋作成・参加・対戦に接続しています。

記録専用GASは正式版とは別の新規プロジェクトに作成し、非表示iframeのBridgeを介して接続しました。対戦はさらに別のGASプロジェクトで現在の9関数を通信対象とします。対戦クライアントは`battleApiOnce`の通信共通入口を差し替え、元のACK・sequence・重複攻撃防止・再接続等を維持しました。追加で、元版の空のメッセージでも通信エラー文が表示される不具合を1行修正し、メニュー・操作前にエラー表示を消せるようにしました。サーバーコード、管理情報、ロールバックZIP、内部資料はこの公開フォルダーに含めません。

対戦BridgeもGAS URL・origin・iframeの送信元・channel・requestIdを確認します。元の処理が再送を管理し、Bridgeは要求を自動再実行しません。対戦サーバーは元の関数名を非公開名へ変更した以外、状態遷移と処理本文を維持しています。公開入口は`doGet`と固定9メソッドを扱う`battleBridgeCall`だけで、管理・記録関数を呼べません。部屋・匿名セッション・盤面の保存は新規対戦プロジェクトに分離します。

記録クライアントはGAS URL・origin・iframeの送信元・channel・requestIdを確認し、接続と応答のタイムアウトを持ちます。再送はゲーム側だけが行い、通信層は書き込みを自動再実行しません。GAS側は固定の2メソッドへ振り分け、元のサーバー関数と管理関数を末尾`_`の非公開関数にします。保存内容はプレイ結果だけです。通常記録の重複判定と書き込みを同じScriptLockで囲み、同時再送の重複を防ぎます。統計計算はロック外で行います。

現在の匿名方針を維持し、氏名・メールアドレス・Googleアカウント・学校名・学年・クラスを新たに保存しません。保存列とモードごとの保存先分離を実GASで確認しました。検査用の記録表を別に保管し、公開用の表はヘッダーだけの空の状態から開始します。

## 公開と更新の手順

紹介文・カバー画像と最終公開は承認済みです。今後の更新でも公開前の差分を確認します。公開前にリモートmainの最新SHAと作業ブランチSHA、変更一覧を記録し、最新mainに追加された他作品の変更を維持します。ローカルmainが古い場合は、それを公開版の基準にしません。

一般公開用の記録・対戦GASでlocalhostの開発許可を無効にしてから、承認された `apps.json` の10の塔だけを公開中へ変更します。カバーは正式素材をそのままコピーして登録し、ルートの変更されていない `build.cjs` を実行してHTML・サイトマップを生成します。生成後の差分、通常URL、Bridgeの接続を確認して作業ブランチを反映します。

フロントの変更はこのフォルダーで行い、素材キーと相対パスを維持します。バックエンドの変更は一般公開用の各GASプロジェクトだけで行い、新しいバージョンを同じWebアプリのデプロイへ割り当てます。URLが変わった場合にだけ `config.js` を更新します。公開GASの固定メソッド、送信元確認、匿名保存、記録用と対戦用の分離を維持してください。

## ロールバック

公開前にはmain・既存公開アプリ・正式GASを変更せず、作業ブランチで検査しました。公開後は以下の手順で取り消します。元GASのZIPと内部検査資料は公開リポジトリ外に保持します。

公開直前には旧main SHA・作業ブランチSHA・変更ファイル一覧を保存します。公開後に問題が出た場合は、最新mainから修正ブランチを作り、公開用マージコミットだけを `git revert -m 1 <公開マージSHA>` で取り消します。内容を確認して再配信し、10の塔のカードが準備中へ戻ったことと他作品が維持されていることを確認します。main全体を古いSHAへ巻き戻しません。スカッシュで取り込んだ場合は `-m 1` を付けず、その公開コミットをrevertします。

GAS側を変更した場合も一般公開用の以前のバージョンへ同じデプロイを戻し、正式GASの母艦へ上書きしません。記録表や匿名対戦の保存データを削除して戻す手順はありません。実際の対象SHAと配信結果は最終公開時に記録します。
