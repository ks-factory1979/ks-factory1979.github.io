# ひらがなタウンをつくろう！

ひらがなを読んで絵を選び、宝箱から集めたアイテムで町をつくる学習ゲームです。あ行〜わ行の220語を収録しています。

## 遊ぶ

https://ks-factory1979.github.io/hiragana-town/

## 音楽

最初のタップ、またはEnter・スペースキーで音楽が始まります。初期音量は30%です。画面下の「おんがく」でオン・オフ、「おとの おおきさ」で音量を変えられます。設定はこの端末・ブラウザに保存され、町の記録とは別に扱います。

- タイトル・行選択：`audio/hiragana_town_title_loop.mp3`
- クイズ：`audio/hiragana_town_quiz_loop.mp3`
- 町づくり・宝箱：`audio/hiragana_town_town_loop.mp3`

画面に応じて約0.4秒でフェードして切り替えます。同じ画面内で問題が変わっても曲は続きます。タブを隠したときは停止し、戻ると続きから再開します。音楽の読み込みに失敗してもゲームは続けられます。

提供されたMP3は再圧縮せずそのまま収録しています。`bgm.js` が読み込み後の音声の末尾と先頭を12ミリ秒だけクロスフェードして、境目の段差を抑えます。ループ1周はこの分だけ短くなります。Web Audioのバッファで連続ループするため、曲の終わりに再読み込みは発生しません。音楽は最初の操作後、必要な曲だけ読み込みます。

## 保存と引き継ぎ

記録は利用中の端末・ブラウザのlocalStorageに保存します。GAS版から自動では移りません。元のGAS版の「せんせい」→「セーブを書き出す」で保存し、公開版の同じメニューから読み込んでください。別の端末・ブラウザへの移動も同じ方法です。共有端末では同じブラウザの利用者が同じ町を使います。

「問題データのキャッシュを消す」は町の記録を消しません。「町の記録をリセット」は、このブラウザの記録を消します。

## 構成

- index.html / style.css / game.js：画面・ゲーム本体
- bgm.js / audio/*.mp3：音楽の再生・ループ処理と3曲の音源
- assets.js / manifest.js：画像の場所・220語の一覧
- pack-*.json：行ごとの問題データ
- ui-* / word-*：元データと同じ画像。変更検知用のハッシュをファイル名に含めています。

GAS・Google Drive・スプレッドシート・外部ライブラリへの接続はありません。問題一覧は行ごと、画像は必要になったときに読み込みます。問題一覧はIndexedDB、画像は通常のブラウザキャッシュを利用します。完全オフライン動作は保証しません。

ゲームは氏名・メールアドレス・利用者IDを収集せず、進捗をサーバーへ送りません。配信サービスGitHub Pages自体はセキュリティのためIPアドレスを記録します。詳細：https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

GAS版の動作を引き継いだGitHub Pages版 1.2.1-pages。元の学校用GAS・Driveファイルは変更していません。
