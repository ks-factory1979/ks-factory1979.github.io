# ひらがなタウンをつくろう！

ひらがなを読んで絵を選び、宝箱から集めたアイテムで町をつくる学習ゲームです。あ行〜わ行の220語を収録しています。

## 遊ぶ

https://ks-factory1979.github.io/hiragana-town/

## 音楽

最初のタップ、またはEnter・スペースキーで音楽が始まります。初期音量は30%です。画面下の「おんがく」でオン・オフ、「おとの おおきさ」で音量を変えられます。設定はこの端末・ブラウザに保存され、町の記録とは別に扱います。

スマホ（横幅620px以下）では、右下の「♪」から音楽設定を開きます。パネルの×、♪の再タップ、パネル外のタップ、Escapeキーで閉じられます。PC・タブレットでは従来どおり下部に音楽の操作を表示します。音楽エンジン・曲・ループ・フェード処理は変更していません。

- タイトル・行選択：`audio/hiragana_town_title_loop.mp3`
- クイズ：`audio/hiragana_town_quiz_loop.mp3`
- 町づくり・宝箱：`audio/hiragana_town_town_loop.mp3`

画面に応じて約0.4秒でフェードして切り替えます。同じ画面内で問題が変わっても曲は続きます。タブを隠したときは停止し、戻ると続きから再開します。音楽の読み込みに失敗してもゲームは続けられます。

提供されたMP3は再圧縮せずそのまま収録しています。`bgm.js` が読み込み後の音声の末尾と先頭を12ミリ秒だけクロスフェードして、境目の段差を抑えます。ループ1周はこの分だけ短くなります。Web Audioのバッファで連続ループするため、曲の終わりに再読み込みは発生しません。音楽は最初の操作後、必要な曲だけ読み込みます。

## 保存と引き継ぎ

記録は利用中の端末・ブラウザのlocalStorageに保存します。GAS版から自動では移りません。元のGAS版の「せんせい」→「セーブを書き出す」で保存し、公開版の同じメニューから読み込んでください。別の端末・ブラウザへの移動も同じ方法です。共有端末では同じブラウザの利用者が同じ町を使います。

「問題データのキャッシュを消す」は町の記録を消しません。「町の記録をリセット」は、このブラウザの記録を消します。

## スマホ最適化 v1（1.2.2-pages）

- 問題語はすべての画面幅で1行表示します。DOMの実測幅とカード内の利用可能幅を比較し、はみ出す場合だけ字間と文字サイズを縮めます。新しい問題・画面表示・サイズ変更・回転・フォント読み込み完了時に再計算し、短い語ではCSSの元の大きさに戻します。
- 横幅620px以下では横3択のままカード内余白を6pxに減らし、画像は最大90%の領域まで使用します。画像の縦横比と正誤演出は維持します。狭い横持ちでも縦長画像が枠を超えないようにしています。
- 問題・町ヘッダーの行変更ボタンを「ぎょう」に短縮し、読み上げ名「ぎょうを かえる」は維持します。主要なスマホ操作は44px以上のタップ領域を確保します。行選択は従来の2列表示です。
- 町のズームはスマホのみ「🔍」から開く小型パネルに収納します。同じボタン・パネル外のタップ・Escapeキーで閉じられます。既存のスライダーと`applyZoom`をそのまま使います。音楽・ズームのパネルは同時には開かず、画面変更で閉じます。
- 対応ブラウザでは`100dvh`を使用し、従来の高さ指定も残しています。ノッチ・画面端・ホームインジケータの余白、スクロール可能な小画面モーダル、続けるボタン・トーストの位置を調整しています。ホバー演出はマウス・トラックパッドでのみ有効です。
- 初めて町に入ると、短い操作ガイドが表示されます。宝箱がある場合は演出終了後に表示します。ガイドを押すかアイテムを実際に動かすと消え、`hiraganaTownGuide_v1`という専用localStorageキーに記録します。保存できない環境でも、その起動中は再表示しません。町のセーブ形式・保存キーとは独立しています。

問題220語・出題ルール・宝箱・町画像と配置・ドラッグと自動スクロール・ズームの座標変換・IndexedDBキャッシュ・既存セーブの取り込み仕様は維持しています。PC・タブレットには、1行フィットと初回ガイド、必要な画面端の余白以外は基本のレイアウトを適用します。

### 検証（2026-09-13）

Windows上のEdgeで、320×568・375×667・393×852・430×932・844×390・768×1024・1280×800の表示を確認しました。320px幅では220語すべてが1行に収まり、この環境で最小の文字サイズは29.3pxでした。指定の5語、縦横回転、Safe Area相当の余白、横3択と画像の収まり、ヘッダー、音楽・ズームパネルの開閉とキーボード操作を確認しています。

タッチイベントによる町のドラッグ・自動スクロール・空白部分のスクロール、初回ガイドのタップ／ドラッグでの消去と再読込後の記憶、ズーム35〜110%で44px以上のアイテム判定も確認しました。行別／ぜんぶから、5問、正誤演出、復習登録、初回正解の取得、宝箱、次の5問、先生メニュー、セーブ書き出し・旧Pages／GAS形式相当の読み込み、キャッシュ削除、リセット、BGMの基本操作・非表示時の停止／復帰のテストを実施しています。PC・タブレット幅では改修前の主要UIの寸法・余白・文字サイズとの一致も確認しました。

iPhone・iPadの実機Safari、Android実機、Chromebook実機は未確認です。Safe Areaとタブ非表示・復帰はブラウザ上で状態を再現した確認であり、実機のブラウザバー・OSの音声制御を含む試験ではありません。

## 構成

- index.html / style.css / game.js：画面・ゲーム本体
- bgm.js / audio/*.mp3：音楽の再生・ループ処理と3曲の音源
- assets.js / manifest.js：画像の場所・220語の一覧
- pack-*.json：行ごとの問題データ
- ui-* / word-*：元データと同じ画像。変更検知用のハッシュをファイル名に含めています。

GAS・Google Drive・スプレッドシート・外部ライブラリへの接続はありません。問題一覧は行ごと、画像は必要になったときに読み込みます。問題一覧はIndexedDB、画像は通常のブラウザキャッシュを利用します。完全オフライン動作は保証しません。

ゲームは氏名・メールアドレス・利用者IDを収集せず、進捗をサーバーへ送りません。配信サービスGitHub Pages自体はセキュリティのためIPアドレスを記録します。詳細：https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages

GAS版の動作を引き継いだGitHub Pages版 1.2.2-pages。元の学校用GAS・Driveファイルは変更していません。
