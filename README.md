# K's Factory 教育アプリ

学校やおうちで使える教育アプリのポータルサイトです。

公開先: https://ks-factory1979.github.io/

## アプリの追加・変更

1. `apps.json` の `apps` に作品情報を追加します。
2. 公開済みの作品は `status` を `published` にして、HTTPSのゲームURLを設定します。
3. 紹介画像を同じフォルダーに置き、`cover` にファイル名を指定します。
4. Node.jsで `node build.cjs` を実行すると `index.html` が更新されます。
5. 更新したファイルをGitHubへ登録すると、GitHub Pagesに反映されます。

`status` が `coming-soon` の作品は、名前と「準備中」だけを表示します。その他の状態の作品は表示しません。未公開のゲームURLや運営用の情報をこのリポジトリへ入れないでください。

掲載する作品の記録保存やアクセス条件は、それぞれのアプリに依存します。このポータルには利用者の入力フォーム、アクセス解析、Cookieやローカル保存を使う処理を設けていません。配信サービス側の標準ログとは別です。

タイピング村のゲーム本体・GAS管理コード・管理シート・認証情報は、このリポジトリには含みません。紹介画像は同作品の提供素材から使用しています。
