# K's Factory 教育アプリ

学校やおうちで使える教育アプリのポータルサイトです。

公開先: https://ks-factory1979.github.io/

## アプリの追加・変更

1. `apps.json` の `apps` に作品情報を追加します。
2. 公開済みの作品は `status` を `published` にして、HTTPSのゲームURLを設定します。
3. 紹介画像を同じフォルダーに置き、`cover` にファイル名を指定します。
4. Node.jsで `node build.cjs` を実行すると `index.html` が更新されます。
5. 更新したファイルをGitHubへ登録すると、GitHub Pagesに反映されます。

`status` が `coming-soon` の作品は、名前と「準備中」だけを表示します。その他の状態の作品は表示しません。未公開のゲームURLや運営用の情報をこのリポジトリへ入れないでください。

掲載する作品の記録保存やアクセス条件は、それぞれのアプリに依存します。このポータルには利用者の入力フォームやCookie・ローカル保存を使う独自処理を設けていません。アクセスカウンターは合計数と集計開始日だけを運営用GASに保存します。GitHub・Google側の標準ログとは別です。

タイピング村のゲーム本体・GAS管理コード・管理シート・認証情報は、このリポジトリには含みません。紹介画像は同作品の提供素材から使用しています。

## Google検索向けの設定

`build.cjs` は、検索用のタイトル・説明・正式URL・WebSite構造化データを含むHTMLに加えて、`robots.txt` と `sitemap.xml` を生成します。サイトマップには、このサイトで公開しているページの正式URLだけを載せます。別の配信先にあるゲーム本体のURLや、準備中の作品は入れていません。

`googleSiteVerification` は、Search Consoleで運営者の所有権を確認するため、ページ内へ公開する専用の確認コードです。ログイン用のパスワードやAPIキーではありません。確認後も削除せず、サイトの更新時に引き継ぎます。

検索への掲載や掲載順位はGoogleの判断によります。Search Consoleで登録状況を確認し、ページを追加した際はサイトマップも更新してください。

## 累計アクセスカウンター

`apps.json` の `counterUrl` に、カウンター専用GASの公開URLを設定しています。`counter.js` がページ表示時に1回加算し、公開されている合計を読み取って表示します。サイト更新時はこのURLを維持してください。空にして再生成するとカウンターとその通信を無効にできます。

集計は設置時から開始し、それ以前のアクセスは含めません。再読み込み・運営者の確認も含む延べ回数で、人数・ゲームのプレイ回数ではありません。Cookie・利用者ID・IPアドレス・学校名・名前・個別の閲覧履歴はカウンターの保存データに含めていません。読み取りは公開の合計だけで、加算口には任意の数値設定やリセット機能がありません。

通信が失敗したときは「ただいま集計を確認できません」と表示し、ゲームへのリンクはそのまま使えます。通信制限、JavaScript無効化、GASの利用上限などによって集計できないアクセスがあり、機械的なアクセスや繰り返し送信を厳密には除外しません。正確な人数分析には使用しないでください。
