# ひっぱれ！けいさんバトル

GitHub Pages移植版 **v1.3.0**。移植元はGAS正式版v1.2.4です。
計算問題、CPU、演出、キャラクターと綱の位置設定、ゲームルール（`lion-rules-3`）を引き継いでいます。

公開URL: https://ks-factory1979.github.io/calculation-battle/

## 配信と共有データ

HTML・CSS・JavaScript・画像をGitHub Pagesから配信します。通常CPU戦と2人対戦は共有サーバーへ接続できなくても遊べます。
起動時の王者情報、必要なゴースト、公式戦終了後の結果は、非表示のGAS Bridgeを介して既存のGASへ送ります。試合中に新しい共有データ要求を開始しません。
共有機能には既存GASへのアクセス権が必要です。現在のGASは学校組織内向けの公開設定を引き継いでいます。

GAS側が公式記録の妥当性と月間王者を判定し、既存のGoogle Sheetsに保存します。元のGASゲームは並行運用できます。

## 保存内容

- ブラウザ内: 端末識別ID、公式記録の送信待ち、ライオン撃破状況、先月王者の表示済み状態。
- 共有保存: 公式プレイ記録、月間王者、ゴースト、保存トランザクション。氏名入力はありません。

保存を確認するまで送信待ちを保持し、次回起動時に同じプレイID・内容で再送します。ブラウザの保存領域を削除すると未送信記録や端末状態を失います。
GAS版とGitHub版は保存元のサイトが異なるため、GAS版の端末IDや未送信キューは自動共有されません。既存の共有プレイ記録と王者・ゴーストは引き続きGASに残ります。
