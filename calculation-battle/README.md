# ひっぱれ！けいさんバトル

GitHub Pages移植版 **v1.3.2**。移植元はGAS正式版v1.2.4です。
計算問題、CPU、演出、キャラクターと綱の位置設定、ゲームルール（`lion-rules-3`）を引き継いでいます。

公開URL: https://ks-factory1979.github.io/calculation-battle/

## スマートフォン対応

- スマートフォンの縦画面・横画面・高さの低い横画面に対応しています。
- 全画面表示に対応していない端末でも、通常のブラウザ表示でプレイできます。
- 2人対戦はスマートフォンを縦向きにして遊びます。
- 主要画面は画面全体をスクロールせず、問題選択のコース一覧だけを内部スクロールできます。

## 配信と共有データ

HTML・CSS・JavaScript・画像をGitHub Pagesから配信します。通常CPU戦と2人対戦は共有サーバーへ接続できなくても遊べます。
起動時の王者情報、必要なゴースト、公式戦終了後の結果は、非表示のGAS Bridgeを介してK's Factory一般公開バックエンドへ送ります。試合中に新しい共有データ要求を開始しません。
共有機能はGoogleログインなしで利用できます。

GAS側が公式記録の妥当性と月間王者を判定し、一般公開版専用のGoogle Sheetsに保存します。学校版GAS・学校版スプレッドシートとは分離されており、学校版の記録や王者は共有しません。

公式戦ではGASが案内する記録互換バージョンを送信し、実際の画面バージョンも診断用に添えます。対象外の場合は、一時停止・画面離脱・バージョン不一致・記録データ不整合などを子ども向けの理由別メッセージで案内します。スマートフォンの短い表示状態変化は猶予時間内なら中断扱いにせず、実際の離脱は引き続き公式記録の対象外です。

## 保存内容

- ブラウザ内: 端末識別ID、公式記録の送信待ち、ライオン撃破状況、先月王者の表示済み状態。
- 共有保存: 公式プレイ記録、月間王者、ゴースト、保存トランザクション。氏名・メールアドレスは保存しません。ブラウザで自動発行する端末IDは、サーバー側でハッシュ化して保存します。

保存を確認するまで送信待ちを保持し、次回起動時に同じプレイID・内容で再送します。ブラウザの保存領域を削除すると未送信記録や端末状態を失います。
学校版GASと一般公開版は保存先が異なるため、端末ID、未送信キュー、プレイ記録、王者、ゴーストを相互に共有しません。学校版GASと学校版スプレッドシートはそのまま残ります。

## 開発者用の配置調整モード

URLへ `?positionEdit=1` を付けた場合だけ、実際の対戦画面上で綱・左キャラクター・右キャラクターをドラッグして調整できます。矢印キー、Shift＋矢印、拡大縮小、複数回Undo、対象別・全体リセットにも対応しています。

画面はviewportの幅・高さ・縦横比から `wide`、`compact-landscape`、`portrait` の3種類に分類します。調整値はブラウザ内へ一時保存し、「調整完了・JSON生成」で正式反映用JSONを作ります。このモードからGitHubのコードや共有データへ直接書き込む処理はありません。

正式反映した位置は `game.js` の `BATTLE_POSITION_CONFIG` に保持します。基準画面は横長1366×768、横の中間1024×768、縦390×844です。対戦中の綱・キャラクター・王者ライオンは同じ配置舞台に載せ、舞台の高さに合わせて画像を均等に拡大縮小します。横方向の余白が変わると、綱と左右の間隔だけが伸縮します。画像の縦横比と、基準画面で調整した高さ関係を保つため、画面比ごとに新しい座標を増やす必要はありません。

通常URLでは調整用CSS・JavaScriptを読み込まず、調整パネル、ガイド、ドラッグ操作、編集ブリッジを生成しません。

## 掲載状態

通常CPU戦、月間王者、ゴースト戦、結果送信と再送、音、全画面を確認し、K's Factoryへ正式掲載しています。一般公開バックエンドでは保存、王者更新、同一記録の二重保存防止、端末IDのハッシュ化、ゴースト取得を自動試験しています。
