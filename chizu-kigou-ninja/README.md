# 地図記号忍者 v0.4.9

地図記号を見分けて、正しい札を斬る小学生向け学習アクションです。下忍・中忍・上忍の60種類、修行選択、忍術帖、4属性の刀と忍小判ショップがあります。

公開URL：https://ks-factory1979.github.io/chizu-kigou-ninja/

## 遊び方

「はじめる」から修行を選び、お題と同じ地図記号の札をマウスまたはタッチでスワイプします。横向き推奨です。最初の操作後に音が有効になります。「音の設定」でBGM・効果音・音量を調整できます。
学習記録・小判・購入済みの刀・装備は、同じ端末・ブラウザ内に保存します。共有端末では記録も共有されます。ローカル版や別URLの記録は自動で移りません。
Googleログインや氏名入力はありません。
