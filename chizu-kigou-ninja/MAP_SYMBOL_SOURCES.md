# 地図記号60種類の出典

ゲームv0.4.9で使用する60種類の索引です（記号データはv0.4.7と同一）。下忍・中忍・上忍各20種類。上忍・其ノ一はダムで、老人ホームは下忍に1種類だけあります。

国土地理院の図形・解説をもとに、本ゲームが図形の抽出・再描画・大きさ／描画色の調整、子ども向けの短い説明への編集を行いました。国土地理院の公認・推薦を表すものではありません。

図形は下記の国土地理院の原典に基づいて再描画しています。多くを黒に統一し、ダム本体の灰色は維持しています。公式ページの写真・地図スクリーンショットはゲームに取り込んでいません。

記号そのものの利用については[GSI FAQ A3.9](https://www.gsi.go.jp/kohokocho/FAQ3.html)、解説などの編集利用については[GSI利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)を確認しました。個別の第三者表記を含むページ全体を自由素材とは扱いません。
